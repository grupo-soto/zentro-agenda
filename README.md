# Agenda de Zentromachine (versión de prueba)

El CRM del comercial de Zentromachine, para enseñarlo sin servidor: https://grupo-soto.github.io/zentro-agenda/

Todo pasa en el navegador. Los 10.000 contactos, sus teléfonos, ventas y mensajes son **inventados**; las máquinas son
las del catálogo público. «Llamar» y «WhatsApp» no hacen nada de verdad (modo prueba) y lo que se cambia se pierde al
recargar. En Inicio, «Prueba el WhatsApp automático» enseña cómo funcionará con la API oficial de WhatsApp.

No se edita aquí: se genera desde la carpeta de Grupo Soto con `npm run subir-agenda-prueba`.
